# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through
[GitHub Security Advisories](https://github.com/zahidhasann88/meshlink/security/advisories/new).
Include:

- what you found and its impact
- steps to reproduce
- the MeshLink version or commit

Never include real private keys or tokens.

## Supported versions

MeshLink is in early development (v0.x). Only the latest commit on `main`
receives fixes.

## Learn more

See [docs/security.md](docs/security.md) for how identity and trust work, and
for the threats MeshLink does and does not cover.
